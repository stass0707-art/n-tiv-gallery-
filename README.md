# n-tiv.ru — перенос «Арт-галерея Москва» на Selectel

## ⚡ Быстрый старт: деплой через GitHub Actions (сейчас)

Сервер и SSL уже настроены. Осталось загрузить код на GitHub и запустить автодеплой.

### 1. Создайте репозиторий на GitHub

1. Откройте GitHub в браузере и войдите под аккаунтом `stass0707-art`.
2. Нажмите зелёную кнопку **New** (или **+** → **New repository**).
3. В поле **Repository name** введите: `n-tiv-gallery`.
4. Оставьте **Public** (проще всего) или выберите **Private**.
5. Нажмите **Create repository**.

### 2. Загрузите код через GitHub Desktop

1. Установите **GitHub Desktop** с официального сайта (если ещё не установлен).
2. Войдите под аккаунтом `stass0707-art`.
3. Клонируйте пустой репозиторий `n-tiv-gallery` на компьютер в любую папку.
4. Скопируйте **всё содержимое** папки `n-tiv-gallery/` (подпапки `frontend/`, `backend/`, `infra/` и `.github/`) в клонированную папку на компьютере.
5. В GitHub Desktop введите коммит-сообщение `Initial commit` и нажмите:
   - **Commit to main**
   - **Push origin**

### 3. Добавьте секрет GitHub Actions

1. Откройте репозиторий `n-tiv-gallery` на GitHub.
2. Перейдите в **Settings** → **Secrets and variables** → **Actions**.
3. Нажмите **New repository secret** и добавьте один секрет:

| Имя секрета | Значение |
|---|---|
| `VPS_SSH_KEY_BASE64` | приватный SSH-ключ, преобразованный в одну строку Base64 |

Многострочный секрет `VPS_SSH_KEY` больше не используется. `VPS_HOST` и `VPS_USER` тоже больше не используются: проверенные адрес сервера `45.157.161.97`, пользователь `deploy` и порт `22` зафиксированы в workflow. Это исключает скрытые пробелы, дефисы и другие повреждения значений при копировании в GitHub Secrets.

Workflow сначала восстанавливает ключ из Base64, проверяет его через `ssh-keygen`, отдельно проверяет формат адреса назначения, выполняет диагностическое SSH-подключение и только затем начинает копирование файлов.

### 4. Запустите деплой

1. После push в `main` GitHub Actions автоматически начнёт сборку. Если не начнёт — откройте вкладку **Actions**, выберите workflow **Deploy n-tiv.ru** и нажмите **Run workflow**.
2. Дождитесь зелёной галочки в разделе **Actions**.
3. Проверьте `https://n-tiv.ru` — должен открыться сайт галереи.

### 5. Войдите в админку

1. Откройте `https://n-tiv.ru/admin`.
2. Войдите с данными:
   - Email: `admin@n-tiv.ru`
   - Пароль: `n-tiv-admin-2026`
3. Сразу смените пароль.

## Что уже сделано в коде

- `backend/` — готовый сервер на Node.js 20 + Express + PostgreSQL 16.
  - Роуты публичного API: `/api/works`, `/api/exhibitions`, `/api/events`, `/api/workshops`, `/api/characters`, `/api/posts`, `/api/texts`.
  - Роуты админки: `/api/admin/:entity`, `/api/admin/texts`, `/api/admin/leads`, `/api/admin/upload`.
  - Авторизация по httpOnly-cookie-сессии: `/api/auth/login`, `/api/auth/logout`, `/api/auth/me`.
  - Миграции и начальная схема БД в `backend/src/migrations/`.
- `frontend/` — скопирован и адаптирован из `src/gallery-demo/`.
  - Все данные теперь загружаются с API, а не из `localStorage`.
  - Админка отправляет изменения на сервер через `saveWork`, `saveEvent`, `saveExhibition`, `saveWorkshop`, `saveCharacter`, `savePost`, `updateText`.
  - Вход в админку — реальный email/пароль через `/api/auth/login`.
  - Сборка фронтенда проходит (`bun run build`) и выкладывается в `dist/`.
- `infra/server-setup.sh` — автоматическая первичная настройка сервера.
- `infra/setup-all.sh` — скрипт, который объединяет `server-setup.sh` и настройку nginx.
- `infra/ssl.sh` — получение SSL-сертификата Let's Encrypt (запускать после смены DNS).
- `infra/nginx-n-tiv.conf` — конфигурация nginx для `n-tiv.ru` и `www.n-tiv.ru`.
- `.github/workflows/deploy.yml` — автодеплой из репозитория `n-tiv-gallery` на Selectel через GitHub Actions.

## Что сделать в Selectel прямо сейчас

### Шаг 1. Проверьте блок «Доступ» и выберите способ входа

1. Вернитесь к форме создания сервера, прокрутите вниз до блока **«Доступ»**.
2. Если у вас есть SSH-ключ — выберите его.
3. Если SSH-ключа нет — выберите **доступ по паролю**.
4. Сохраните пароль в менеджер паролей (Bitwarden, KeePass и т.п.). Не присылайте его в чат и не храните в открытом виде.

### Шаг 2. Пополните баланс

1. Вверху страницы виден баланс **2 215,98 ₽ ≈ 1 месяц**.
2. Нажмите на сумму баланса или перейдите в раздел **«Биллинг» → Пополнить баланс**.
3. Пополните минимум на **3 500 ₽** (один месяц + запас), чтобы сервер не удалили при уходе в минус.

### Шаг 3. Создайте сервер

1. Нажмите чёрную кнопку **«Создать сервер»**.
2. Дождитесь статуса сервера **ACTIVE**. Это обычно занимает 3–10 минут.

### Шаг 4. Откройте сетевые порты

1. В левом меню Selectel выберите **«Группы безопасности»**.
2. Откройте группу **default** (или ту, что привязана к серверу).
3. Перейдите на вкладку **«Входящий трафик»** или **«Правила»**.
4. Нажмите **«Добавить правило»** и добавьте три правила по очереди:

| Протокол | Порт | Источник | Описание |
|---|---|---|---|
| TCP | 22 | 0.0.0.0/0 | SSH |
| TCP | 80 | 0.0.0.0/0 | HTTP |
| TCP | 443 | 0.0.0.0/0 | HTTPS |

5. Нажмите **«Сохранить»**.

### Шаг 5. Скопируйте публичный IP

1. Перейдите в **«Серверы»**.
2. Откройте карточку сервера `n-tiv-production`.
3. Найдите строку **«Публичные IP»** и скопируйте IP-адрес.
4. Пришлите этот IP в чат (без пароля). После этого мы проверим SSH и продолжим настройку.

## Что будет дальше (после получения IP)

1. Подключаемся по SSH и запускаем скрипт первичной настройки `infra/setup-all.sh` (или по отдельности `server-setup.sh`, затем копируем `nginx-n-tiv.conf` в `/etc/nginx/sites-available/`).
2. Скрипт установит nginx, PostgreSQL 16, Node.js 20, pm2, certbot, ufw, создаст пользователя `deploy` и базу данных `n_tiv`.
3. Создаём репозиторий `n-tiv-gallery` на GitHub, заливаем туда `frontend/`, `backend/`, `infra/` и `.github/workflows/deploy.yml`.
4. Добавляем единственный секрет GitHub Actions: `VPS_SSH_KEY_BASE64`. Адрес, пользователь и порт уже зафиксированы в workflow.
5. Делаем первый push — автодеплой выкладывает сайт и бэкенд на сервер.
6. Меняем A-записи `n-tiv.ru` и `www.n-tiv.ru` в Reg.ru на IP сервера.
7. Запускаем на сервере `infra/ssl.sh` для получения SSL-сертификата (Let's Encrypt проверяет домен, поэтому SSL — только после обновления DNS).
8. Проверяем работу сайта и админки на `https://n-tiv.ru`.

4. Реальный контент: тексты, фото работ, данные персон, контакты, реквизиты.

## Примечание по безопасности

- Пароль `n-tiv-admin-2026` указан только в миграции `backend/src/migrations/001_initial.sql` и в этом README. После первого входа в админку его необходимо сменить.
- PostgreSQL настроена на прослушивание только localhost.
- Вход по root через SSH будет отключён скриптом `server-setup.sh`.
- Рекомендуется сразу настроить SSH-ключ для пользователя `deploy` и отключить вход по паролю после первичной настройки.
